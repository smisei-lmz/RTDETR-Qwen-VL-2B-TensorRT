## 今日学习与实现

需要掌握：有界队列、drop-oldest、尾延迟。

比较 queue=1/2/8；输入 120fps，模拟处理 60ms；从 JSON 记录丢帧数和 p99。

本目录的 `run.py` 是当天可执行实验入口；具体实现已写在下面列出的共享源文件中。先运行，再逐段阅读，最后完成上面的参数对比/修改任务。每日共享实现是为了让你维护同一套完整系统，而不是复制 37 份不一致的代码。

## 运行

在项目根目录、已激活的 WSL Python 环境中执行（板端阶段改为板上终端）：

```bash
python days/day10/run.py
```



正常运行结束应返回 0；故障实验的预期错误由课程入口捕获并核对。

运行参数会保存到 `runs/day10/invocation.json`。实际实验数据写入该目录，模型共享产物位于 `artifacts/`，图片位于 `data/`；具体命令也会打印。自动脚本返回成功仅表示命令成功，下面的人工验收仍需完成。

## 验收

队列高水位不超过配置；只丢尚未提交的帧；确认大队列可能提高旧帧等待时间；不把丢帧隐藏成满帧率。

将命令、环境、实际输出、问题原因和你修改的代码写入 `runs/day10/notes.md`。未安装依赖、跳过、只读过源码与通过验收是四种不同状态。
