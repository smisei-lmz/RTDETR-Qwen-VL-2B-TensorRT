## 今日学习与实现

需要掌握：EXPBUF、fd 与像素地址区别。

对 MMAP buffer 执行 EXPBUF，记录支持与否；研究 fd 所有者、关闭时机和缓存一致性。

本目录的 `run.py` 是当天可执行实验入口；具体实现已写在下面列出的共享源文件中。先运行，再逐段阅读，最后完成上面的参数对比/修改任务。每日共享实现是为了让你维护同一套完整系统，而不是复制 37 份不一致的代码。

## 运行

在项目根目录、已激活的 WSL Python 环境中执行（板端阶段改为板上终端）：

```bash
python days/day33/run.py
```



正常运行结束应返回 0；故障实验的预期错误由课程入口捕获并核对。 必须在 Jetson 上运行；PC 不会伪装板端结果。

运行参数会保存到 `runs/day33/invocation.json`。实际实验数据写入该目录，模型共享产物位于 `artifacts/`，图片位于 `data/`；具体命令也会打印。自动脚本返回成功仅表示命令成功，下面的人工验收仍需完成。
