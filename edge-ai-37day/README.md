# 端侧视觉检测与VLM协同推理优化

2026-10-19 实施对齐：当前 DETR 主线位于上一级 `cpp/`，实际模型为
**Ultralytics RT-DETR-L**，沿用已经完成的部署与量化工作。
统一配置和本轮精度、稳定性验收入口见 [C++ README](../cpp/README.md)。
下文现有 `pc/`、Python ROS 和 RT-DETRv2-S 工具保留为旧实现参考，
不代表已经接入当前 C++ lane。

面向端侧部署、C++与推理优化岗位，在现有NVIDIA GPU电脑上开发，再迁移到Jetson Orin Nano 8GB / Super。应用场景为工位离席巡检：DETR持续检测，确认离席后由VLM分析固定图片并生成检查报告。

**核心问题：怎样让TensorRT检测与llama.cpp VLM在共享GPU和有限内存下正确运行，并控制延迟、内存和请求积压？**

## 项目分工

- RK3588多光谱项目：Sensor、ISP、RGA、DMA-BUF、RKNN与NPU数据通路。
- 本项目：CUDA、TensorRT、llama.cpp、C++运行时与双模型资源竞争。

DMA-BUF/EGL、INT8与CUDA Graph为选做实验，按瓶颈决定。正式主线使用固定视频或现成相机输入；运行时业务节点规划为C++，模型导出与实验分析保留Python。
